# weeks/ — filled check-ins

One file per week, copied from `../checkin-template.md` and filled in Sunday evening:

```
weeks/week-01.md … weeks/week-12.md
```

Each is the week's artifact: the five answers in the template, a link to whatever the week
produced (a query output, a scorecard, a control chart), and one journal line. `../ledger.md` holds
one row per week — the ledger is the score, these files are the evidence behind it.

The directory exists in the repository so the paths in `../README.md`, `../DESIGN.md` and
`../mastery-tests.md` resolve in a fresh clone. Week files are added as the plan runs; nothing
here is pre-written, because a pre-filled check-in would be a fabricated artifact.
